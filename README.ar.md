# DealHunter (بالعربي)

تكتب المنتج اللي عايزه بكلامك، والـ agent يفهم طلبك بالـ LLM، يدوّر في المتاجر، يقرا المنتجات، يستبعد اللي مش مناسب، ويرجعلك الأرخص.

## تشغيل محلي
```bash
pip install -r requirements.txt
uvicorn app.main:app --reload       # افتح http://localhost:8000
DEMO=1 uvicorn app.main:app         # وضع تجريبي من صفحات عينة (من غير إنترنت)
pytest -q                           # الاختبارات
```

## مفتاح الـ LLM (مجاني)
خد مفتاح مجاني من https://aistudio.google.com/apikey، وانسخ `.env.example` باسم `.env` وحط المفتاح فيه.
من غير مفتاح الموقع بيشتغل بقواعد بسيطة بس.

## إزاي الـ agent بيشتغل (`app/agent.py`)
1. **يفهم:** الـ LLM يقرا الطلب ويطلع جمل بحث وشروط وميزانية. لو العميل وصف احتياجه بس ("موبايل بطاريته تكمل يومين")، الـ LLM يحوله لمواصفات (بطارية 5000 مللي فأكتر) ويقترح موديلات مناسبة يدوّر عليها.
   **محادثة:** الصفحة بتبعت المحادثة كلها لـ `POST /api/chat`، فرسالة زي "سامسونج بس" بتتدمج مع الطلب اللي قبلها بدل ما تبقى بحث جديد. لو الطلب غامض جداً ("عايز هدية") بيسأل سؤال واحد بإجابات سريعة. (`GET /api/search?q=` لسه شغال لطلب واحد.)
2. **يلاقي:** كل جملة بحث بتتعمل مرتين في نفس الوقت: مرة في المتاجر المشهورة ومرة في باقي المتاجر، والصفحات بتتقسم بالتساوي بين المجموعتين. مفيش بحث مخصوص لأي متجر.
3. **يتأكد:** يفتح كل صفحة بنفسه ويقرا المنتجات والأسعار بالجنيه من بيانات الصفحة (`app/extract.py`)، فالسعر دايماً من المتجر مش من الـ LLM.
4. **يحكم:** الـ LLM يسيب المنتجات المطابقة من متاجر حقيقية بس، ويستبعد المستعمل والمواقع المشبوهة.
5. **يرتب:** من الأرخص، مع نسبة الخصم الحقيقية وبادج "أحسن عرض". أي متجر غير مشهور بياخد درجة ثقة من صفحته (رقم مصري، دفع عند الاستلام، استرجاع، ضمان، عنوان) في `app/trust.py`.

من غير مفتاح Tavily بيرجع يدوّر في بي تك بس (احتياطي).

## نشر مجاني
- **Hugging Face Spaces** (مجاني من غير كارت): اعمل حساب، وخد توكن Write من huggingface.co/settings/tokens وحطه في `.env` باسم `HF_TOKEN`، وبعدين:
  `pip install huggingface_hub` ثم `python -m scripts.deploy_hf`. السكربت بيعمل الـ Space وبيحط مفاتيحك كـ secrets مخفية وبيرفع الكود (من غير `.env` ولا الداتا). نفس الأمر بيحدّث الموقع بعد أي تعديل.
- أونلاين كل زائر ليه `DAILY_LIMIT` بحث جديد في اليوم (5 افتراضيًا) عشان الحصص المجانية تكفي، والبحث المتكرر من الكاش مش بيتحسب.
- زرار "النتيجة دي غلط؟" تحت كل نتيجة بيحفظ البلاغ، وتشوف البلاغات بـ `python -m scripts.reports`.
- **Render**: Web Service من الريبو، Docker، الخطة Free.

## الملفات
- `app/agent.py` الـ agent
- `app/llm.py` الاتصال بـ Gemini
- `app/websearch.py` بحث الويب
- `app/trust.py` سمعة المتاجر
- `app/fetchers.py` قراءة الصفحات اللي مابتفتحش (Tavily Extract ثم Jina Reader) مع احترام robots.txt
- `app/db.py` قاعدة الأسعار (SQLite في `data/prices.db`): كاش للطلبات وتاريخ سعر كل منتج، و`/api/history?url=` بيرجع تاريخ السعر
- `app/market.py` إعداد البلد (MARKET=EG/SA/AE): العملة والدومينات المحلية
- `scripts/benchmark.py` اختبار ثابت بـ 20 طلب حقيقي: `python -m scripts.benchmark 5` والتقرير في `debug/benchmark/`
- `app/extract.py` استخراج المنتجات من أي صفحة
- `app/query.py` و `app/ranking.py` الفهم البسيط (لما مفيش مفتاح)
- `app/stores/` متجر لكل ملف. متجر جديد = كلاس جديد + إضافته في `ALL_STORES`
- `static/index.html` الصفحة
